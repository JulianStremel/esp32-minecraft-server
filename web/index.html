ESP32 Minecraft server

A Minecraft Java Edition 1.21.8 server on an ESP32-S3. Flash it from this page and set up its WiFi; no tools to install.

Use Chrome or Edge on a desktop computer (the page needs Web Serial). You need an ESP32-S3 board with at least 8 MB flash and 8 MB octal PSRAM (N8R8, N16R8 or N16R16 modules) and a USB data cable.

This browser cannot flash boards: open the page in desktop Chrome or Edge. Flashing needs a secure context: open this page over https.

Steps

  1. Plug the board in and press Connect, then pick its serial port. If none shows up, hold the BOOT button while plugging the board in.
  2. Install the firmware. A first install erases the board.
  3. When it asks, pick your WiFi network and enter its password. The board joins it and keeps the setting (Connect again later to change it).
  4. Open the board's status page (the link offered after the WiFi step): it shows the address to enter in Minecraft under Multiplayer → Add Server.

Saving the world: with a FAT32 microSD card in the board's slot the world is kept in a file on it (the prebuilt firmware uses the pins of the Waveshare ESP32-S3-Touch-AMOLED-1.8; a card that does not mount is never formatted). Without a usable card the world lives in memory and starts over after a restart.
Operators: the prebuilt firmware has none; commands can be typed into the serial console. To set operators, other SD pins, network storage and more, build it yourself with include/config.h as in the README.
