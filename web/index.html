ESP32 Minecraft server

Web flasher for the esp32s3-8 firmware (Minecraft 1.16.5).

Use Chrome or Edge on a desktop computer (the page needs Web Serial). Connect an ESP32-S3 board with at least 8 MB flash and 8 MB octal PSRAM (e.g. N8R8 / N16R8 modules) with a USB data cable, press Connect and pick its serial port. If no port shows up, hold the BOOT button while plugging the board in.

This browser cannot flash boards: open the page in desktop Chrome or Edge. Flashing needs a secure context: open this page over https.

This prebuilt firmware ships without embedded WiFi credentials and no world storage. After flashing, ESP Web Tools will ask for your WiFi credentials via Improv Serial. To configure world storage and operators, build it yourself with your settings in include/config.h as described in the README.
